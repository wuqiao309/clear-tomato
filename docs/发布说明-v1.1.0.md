# ClearApp v1.1.0

- 模块包名：`io.github.wuqiao309.clearapp`
- 版本：v1.1.0（versionCode 4）

## 这一版做了什么

### 新增支持：智行火车票 `com.yipiao`（10.25.8）

智行和番茄/红果不是一个架构：底部 tab、「我的」页是原生 View，首页子 tab 和部分模块是 Compose，
首页内容、抢票、订单、支付又是 **CRN（React Native）**。所以规则按「原生 / Compose / CRN」分别处理。

这一版能去掉的东西：

| 位置 | 处理 |
| --- | --- |
| 底部主 tab | 保留 **首页 / 抢票 / 订单 / 我的**；隐藏中间的「超级星期二」活动位 |
| 首页子 tab | 只留 **火车票 / 机票**（去掉 民宿/客栈、酒店） |
| 首页模块 | 隐藏「智行·低价不怕比」及其以下所有模块，上方的工具模块保留 |
| 「我的」页 | 去掉 **我的足迹、周边服务、右下悬浮球、「添加智行福利官」横幅与悬浮球** |
| 订单页 | 去掉 **待支付浮球、加微信推广 banner、酒店推广卡** |
| 去支付 | 「我是全能保障专员」弹窗自动点「否」，流程继续 |
| 已预约 | 进入前的 **邀好友页不再弹出**；「高峰期余票监控」弹窗自动点「暂不开启」 |
| 原生广告 | `TripAdManager` 总开关关闭 + banner 不再加载 |

### 暂时没做的

- **抢票页顶部的「候补管家 / 余票监控」**：CRN 渲染，纯 View 层隐藏会被 RN 重建覆盖，
  需要从 CRN 数据层处理，这一版先放弃。
- **订单信息流里其余服务端推广**：同样是 CRN 服务端下发，文案可识别的部分已处理。

### 番茄 / 红果

规则没有变化，行为和 v1.0.2 一致。

## 适配版本

| app | 包名 | 版本 |
| --- | --- | --- |
| 番茄免费小说 | `com.dragon.read` | 7.3.9.32（73932） |
| 红果免费短剧 | `com.phoenix.read` | 7.3.9.32（73932） |
| 智行火车票 | `com.yipiao` | 10.25.8（710258） |

智行是这一版新适配的，规则里的类名/方法名按 **10.25.8** 写。app 升级后部分规则可能失效，
模块会跳过失效的那条并写日志，不会崩溃。

## 说明

智行的 CRN 页面（首页内容、抢票、订单）是 JS 渲染的，Xposed 改不了视图树。这一版对 CRN 部分
采用「按文案/位置裁剪 View」的方式，属于 UI 层处理：如果宿主重新渲染时把模块设回可见，
可能会再次出现。碰到这种情况把具体位置反馈一下，再针对性处理。
