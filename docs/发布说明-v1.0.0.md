# ClearApp v1.0.0

首个公开版本。

一个 LSPosed 模块，用来把 app 里用不到的东西去掉：多余的 tab、悬浮球、页面组件。不做去广告 ——
只做「界面上这些我不看」。

- 模块包名：`io.github.wuqiao309.clearapp`
- 版本：v1.0.0（versionCode 1）

## 支持范围

| app | 包名 | 适配版本 |
| --- | --- | --- |
| 番茄免费小说 | `com.dragon.read` | 7.3.7.33（versionCode 73733） |
| 红果免费短剧 | `com.phoenix.read` | 7.3.7.32（versionCode 73732） |

## 功能

**番茄免费小说**

- 底部主 tab 只保留 **书城 / 书架 / 我的**（去掉短剧、赚钱、分类）
- 书城顶部子 tab 去掉 **看剧 / 视频 / 商城**
- 书架顶部子 tab 去掉 **收藏**
- 「我的」页去掉 **金币 / 现金余额 / 微信提现 / 福利** 整块，以及底部 **推荐流**
- 悬浮球全部去掉：金币挂件、发帖球、继续看悬浮窗、冷启增长悬浮条

**红果免费短剧**

- 底部主 tab 只保留 **首页 / 剧场 / 我的**（去掉商城、赚钱）
- 悬浮球全部去掉：金币挂件（KMP 版 + 老式版）、一键领挂件、主页面悬浮窗、冷启增长悬浮条

**保留**：番茄听书的「边听边读」悬浮球没有拦 —— 它是跳回阅读器继续听看的功能入口，不是引流组件。
红果「我的」页的金币和提现入口也没动。

## 环境要求

| 项 | 要求 |
| --- | --- |
| Android | 8.0+（API 24+） |
| Root | KernelSU / Magisk |
| Xposed 框架 | **Vector 2.2** 或 **LSPosed**，Xposed API 101+ |

实测环境：红米 K70 至尊版（Android 16）+ KernelSU + Vector 2.2。

## 安装

1. 安装本 release 里的 APK
2. 在 Vector / LSPosed 管理器里启用模块，作用域勾选 `com.dragon.read` 和 `com.phoenix.read`
   （模块已声明 `staticScope`，作用域固定在这两个包上）
3. 强制停止目标 app 再打开

> 装完模块后**第一次冷启可能仍跑的是旧版本**，框架需要一点时间重新读模块。再 force-stop 重启一次
> 即可。

## 说明

- 规则是照着**具体版本**的类名和方法名写的。app 升级后部分规则可能失效。
- 失效是**容错**的：目标方法找不到就跳过那一条并写日志，不会崩溃也不会影响别的规则。日志里搜
  `跳过` 就能看出哪条失效：

  ```bash
  adb logcat -d | grep "ClearApp/"
  ```

- 只作用于设备上已安装的 app，不修改任何 app 的安装包。

## 构建

JDK 21 + Android SDK（platform-35 / build-tools 35.0.0），Gradle wrapper 自带。

```bash
export JAVA_HOME="C:\Program Files\Java\jdk-21"
./gradlew.bat assembleRelease
```

签名密钥不进仓库；未配置时 release 包使用 debug 签名（能装能用，但换签名后覆盖安装需要先卸载）。
