# 当前环境
- 手机： 红米k70至尊版，已开启usb调试
- root：使用月虹提权助手+kernelSu，实现的临时root
- lsposed环境： 基于两个kernelSu模块：ZygiskNext v1.5.0 + Vector v2.2
- 方向项目tools为当前项目开发可能需要的工具

# 目标
- 本项目旨在开发一个lsposed模块
- 用于屏蔽一些app中的无用tab、悬浮窗、以及其他一些页面组件
