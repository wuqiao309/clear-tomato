# ClearApp v1.0.1

适配番茄免费小说 / 红果免费短剧 **7.3.9.32**。

- 模块包名：`io.github.wuqiao309.clearapp`
- 版本：v1.0.1（versionCode 2）

## 为什么发这一版

v1.0.0 发布时适配的是 7.3.7.x，之后两个 app 都自动升级到了 **7.3.9.32**。

番茄/红果的类名分两类：`com.dragon.read.*` 这些是**可读的**，而底层组件是**混淆的**（`r32.o`、
`ma5.o` 这种，包号每次打包都会变）。升级后混淆名全变了，靠可读名的规则都还活着，断的是靠混淆名的
那几条。

模块对这些是**容错**的：目标方法找不到就跳过那一条并写日志，不会崩溃、也不影响别的规则 —— 所以升级
后是「部分失效」而不是「整个坏掉」。这一版就是把断掉的几条按新版本重新映射。

功能与 v1.0.0 一致，没有增删：

**番茄免费小说**

- 底部主 tab 只保留 **书城 / 书架 / 我的**（去掉短剧、赚钱、分类）
- 书城顶部子 tab 去掉 **看剧 / 视频 / 商城**

- 「我的」页去掉 **金币 / 现金余额 / 微信提现 / 福利** 整块，以及底部 **推荐流**
- 悬浮球全部去掉：金币挂件、发帖球、继续看悬浮窗、冷启增长悬浮条

**红果免费短剧**

- 底部主 tab 只保留 **首页 / 剧场 / 我的**（去掉商城、赚钱）

**保留**：番茄听书的「边听边读」悬浮球没有拦 —— 它是跳回阅读器继续听看的功能入口，不是引流组件。
红果「我的」页的金币和提现入口也没动。

## 环境要求

| 项 | 要求 |
| --- | --- |
| Android | 8.0+（API 24+） |
| Root | KernelSU / Magisk |
| Xposed 框架 | **Vector 2.2** 或 **LSPosed**，Xposed API 101+ |

实测环境：红米 K70 至尊版（Android 16）+ KernelSU + Vector 2.2。

## 安装

从本 release 下载 APK 安装，在 LSPosed 管理器里启用模块、勾选 `com.dragon.read` 和
`com.phoenix.read`，然后强制停止目标 app 再打开。

> 装完模块后**第一次冷启可能仍跑的是旧版本**，框架需要一点时间重新读模块。再 force-stop 重启一次
> 即可。

## 升级说明

app 升级后部分规则可能失效。失效是容错的，日志里搜 `跳过` 就能看出哪条断了：

```bash
adb logcat -d | grep "ClearApp/"
```
